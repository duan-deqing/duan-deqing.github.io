- **Project detail pages**: projects with a `slug` now open an in-site detail page; the title, intro and tags reuse the Stack button styling, a back link sits on top, tags link to their own sites, and the repository shows as a GitHub icon plus repo name. The page keeps the article TOC and a background layer.
- **Central icon registry**: new `content/icons.yaml` registry; all SVGs live under `public/images/icons/` grouped by purpose (nav / contacts / stack / hobbies / projects / bookmarks). Nav, contacts, projects, tags and stack items reference names only, while icons, links and brand colors come from the registry.
- **Home Find me on**: contacts are now YAML-driven; clicking the email copies it, and the tooltip on the right changes from "Copy" to a ticked "Copied".
- **Content layout**: `content/` is split by page into `home` / `projects` / `stack` / `blog` / `bookmarks`, shared quotes moved to the root, and unused `site.yaml` fields removed.
- **Test layout**: tests are grouped by domain into `content` / `blog` / `markdown` / `admin` / `site` / `build`.
